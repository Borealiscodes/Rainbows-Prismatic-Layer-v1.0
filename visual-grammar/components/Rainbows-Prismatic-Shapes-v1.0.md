# 🌈 **2. Shape Set (Root‑Derived, Glyph‑Integrated)**  
Each shape begins with a Guided Link so you can deepen it.

### **Raylines** — ➝  
Directional beams representing conceptual flow.  
Used for: intake, projection, refracting.

### **Spectra Bands** — 🌈  
Parallel or curved bands showing decomposed facets.  
Used for: hue, value, chroma, gradient.

### **Chromatic Nodes** — ●  
Anchor points representing structural density or conceptual anchors.  
Used for: recomposition, mapping, anchoring.

### **Gradient Fields** — ▤  
Soft zones showing transitions, shifts, or developmental arcs.  
Used for: pacing, pedagogy, emotional neutrality.

### **Scatter Clouds** — ⁂  
Clusters representing optionality, branching, or non‑linear exploration.  
Used for: ND‑safe branching, non‑directive choice.

### **Prism Frames** — ⧉  
Containers that hold refracted meaning without interpreting it.  
Used for: conceptual framing, epistemic scaffolding.

### **Soft Glyphs** — ✧  
Minimal symbolic markers used for ND‑safe labeling.  
Used for: companions, atmospheres, gentle diagrams.

# 🌈 **4. ND‑Safe Constraints**  
Prismatic Shapes must:

- avoid sharp angles  
- avoid overwhelming density  
- avoid semantic implication  
- avoid diagnostic symbolism  
- avoid activation logic  
- remain optional  
- remain calming  

Shapes are **pre‑semantic** and **sovereignty‑neutral**.
